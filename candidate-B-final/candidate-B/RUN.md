# Запуск

Из папки `candidate-B` выполните команду с Python 3.8 или новее. Достаточно стандартной библиотеки.

```shell
python report.py --date 2026-11-10 --output REPORT.md
```

На Windows вместо `python` можно указать `py -3` или полный путь к интерпретатору. Откройте файл отчёта в просмотрщике Markdown. Для вывода в терминал опустите `--output REPORT.md`. По умолчанию программа читает три CSV из папки `data` рядом со скриптом. Для другой выгрузки того же формата укажите `--data путь_к_папке`.
